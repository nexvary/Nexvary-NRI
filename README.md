# Nexvary Research Intelligence

A bilingual research workspace preview for Arabic and English. The P0 shell uses synthetic examples and can run entirely offline after checkout.

## Run locally

With Node.js 22 or newer:

```sh
npm start
npm test
```

Open [the local dashboard](http://127.0.0.1:3000/). English is available from the top bar. The server binds to loopback by default and accepts a different local port through `PORT`.
